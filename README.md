# FactCheck App Extension

Deze repository bevat een Chrome-extensie die de content van de actieve webpagina factcheckt via de Mistral AI API, weergegeven in een vaste zijbalk (side panel). De applicatie was oorspronkelijk geschreven in Vanilla JS, maar is nu omgezet naar een **Angular 18+** applicatie met behoud van de originele logic.

## Installatie en Bouwen

Omdat dit een Angular project is, dien je het eerst te compileren voordat je het kunt inladen in Chrome.

1. **Installeer de dependencies** (vereist Node.js en npm):
   ```bash
   npm install
   ```

2. **Bouw het project**:
   ```bash
   npm run build
   ```
   *Na het uitvoeren van dit commando verschijnt er een map genaamd `dist/fact-check-app/browser` met daarin de gecompileerde code.*

## Inladen in Chrome / Brave

1. Open je browser en ga naar de extensies beheerpagina:
   - In Chrome of Brave: Navigeer naar `chrome://extensions/`
2. Zet **Developer mode** (Ontwikkelaarsmodus) aan (schakelaar rechtsboven).
3. Klik op **Load unpacked** (Geslaagde extensie laden).
4. Selecteer de volgende map in je project:
   👉 `/pad/naar/project/dist/fact-check-app/browser`
5. Zodra ingeladen kun je de extensie openen! Klik op het extensie-icoon en het Factcheck Panel zal als zijbalk openen.

## Hoe het werkt

- **Sanity check**: Mistral AI scant eerst de tekst om te kijken of het om satire of onzin gaat.
- **Zoeken (Tavily/Web Search)**: Mistral kan indien nodig beslissen de `search_web` tool (Tavily of Brave Search API) aan te roepen om bronnen te raadplegen.
- Alle interacties en Markdown-weergaves worden afgehandeld via Angular Signals.

## Configuratie (API Keys)
De instellingen zoals `API_KEY`, `API_MODEL` en `SEARCH_KEY` bevinden zich in `src/app/config.ts`. In een productie-omgeving wordt aangeraden om een backend server te gebruiken voor API requests in plaats van de keys in de extensie-code te zetten.
